# ClaudeGPT

A clean, beginner-friendly Next.js prototype for a public-facing AI collaboration website.

## What works in this prototype

- Responsive ChatGPT-inspired interface
- Any-topic prompt box and example prompts
- Simulated ChatGPT perspective, Claude critique, rebuttal, and combined final answer
- Copy final answer
- Light/dark appearance toggle
- Editable official ChatGPT and Claude links with buttons to open each service

## Important limitation

This is a **simulated demo**. The messages are generated by local demo logic; the app does not call OpenAI or Anthropic models. Pasting the links to ChatGPT and Claude only opens those sites. Websites cannot automatically exchange messages just because their URLs are entered.

To enable real collaboration, connect the OpenAI and Anthropic APIs through a server-side Next.js route and store API keys in environment variables. Never put secret API keys in client-side code or commit them to a public repository.

## Run locally

Requirements: Node.js 18.17 or later.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Publish it publicly for free

1. Create a GitHub account and a new repository named `claudegpt`.
2. Upload the contents of this project folder to that repository.
3. Sign in to Vercel and import the GitHub repository.
4. Click Deploy. Vercel will give you a public URL.
5. You can connect a custom domain later if you own one.

The prototype requires no API keys and has no paid AI usage. Hosting providers may change their free-plan limits.

## Suggested next step for real AI

Create a server route such as `app/api/collaborate/route.ts` that:
1. Receives the user's prompt.
2. Calls the OpenAI API for a first response.
3. Sends the prompt and first response to the Anthropic API for critique.
4. Optionally asks OpenAI to respond to the critique.
5. Produces a final synthesis and streams updates to the UI.

Add `OPENAI_API_KEY` and `ANTHROPIC_API_KEY` to your hosting provider's server-side environment variables. API usage may cost money even if the website itself is hosted on a free tier.
